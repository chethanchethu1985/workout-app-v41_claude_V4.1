# V4.1 vs V4
- Splash screen: black screen with the animated CB mark, "My Workouts", "Designed by CB" and the version, shown for about 1.5 s while the app loads (tap to skip). Best-effort black Android launch background added in the build workflow.
- Workout Library: three tabs (Workouts, Excel, Media folders) instead of one very long page; one compact list of all 293 workouts with search, category chips with counts, status chips (any / no media / has media / mine), 20 rows per page with "Show more"; tap a row to expand details, media, Start now, Edit/Copy and edit, Remove. Page height at phone width dropped from about 73 screens to about 2.
- Programme lookup made safer against incomplete saved data.
- Version labels and build: Version 4.1, appName My Workouts V4.1, versionName 4.1.0, versionCode 5, artifact My-Workouts-V4.1-APK.
- Unchanged from V4: the 8-week plan, dashboard, calendar, player, health tracker, Excel import, folder card. The V4 package itself was not modified (verified identical to the delivered V4 zip).
